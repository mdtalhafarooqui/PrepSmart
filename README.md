# PrepSmart 🎓

PrepSmart is a responsive web application designed to help students automatically plan their exam preparation in a smart and efficient way. It allows users to add subjects, syllabus topics, exam dates, difficulty levels, and daily available study hours to generate a personalized study timetable.

## ✨ Features
- Add, edit, and manage multiple subjects
- Auto-calculates remaining days before exams
- Generates a smart study timetable
- Allocates more time to high-difficulty subjects
- Progress tracking for completed and pending topics
- Clean, student-friendly dashboard
- Fully responsive design (mobile & desktop)
- Uses LocalStorage (no backend required)

## 🧠 Timetable Logic
The application calculates the number of days remaining until the exam and distributes daily study hours based on subject difficulty and number of topics. Higher difficulty subjects are given more weight, ensuring effective time management without exceeding daily limits.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- LocalStorage

## ▶️ How to Run
1. Download or clone the repository
2. Extract the files
3. Open `index.html` in any modern web browser

## 🎯 Use Case
PrepSmart is ideal for college students and exam aspirants who want an organized, automated, and visually pleasing way to manage their exam preparation.

## 📱 Responsive Design
The interface is optimized for both desktop and mobile devices, providing a professional and smooth user experience.
